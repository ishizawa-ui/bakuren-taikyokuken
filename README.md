# 爆連！太極拳

パズルと太極拳を組み合わせた、スマートフォン対応のWebパズルゲームです。

## 遊び方

- 同じ色の「気」を3つ以上なぞって攻撃します。
- 黄色の玉は、他の玉の2倍だけ必殺技ゲージが増えます。
- ゲージを消費して必殺技を発動し、強敵との対局を勝ち進みます。
- 修行記録は利用中のブラウザー内にのみ保存されます。

## ローカル起動

```bash
npm ci
npm run dev
```

## Renderへの公開

リポジトリ直下の `render.yaml` でStatic Siteを構築します。ビルド時の環境変数やサーバー側のデータベースは使用しません。

## プライバシー

このアプリはアナリティクスや外部APIを使用しません。スコアと到達局は各利用者のブラウザーのLocal Storageにのみ保存され、サーバーへ送信されません。
